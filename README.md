## 📖 CONTEÚDO PROGRAMÁTICO COMPLETO

### 📘 NÍVEL BÁSICO (40 horas)
- Introdução à Informática: história, conceitos e componentes do computador  
- Sistema Operativo Windows: navegação, personalização, pastas, atalhos  
- Pacote Office Essencial: Word, Excel, PowerPoint  
- Noções de Redes: internet, Wi-Fi, navegadores, pesquisa segura  
- Segurança da Informação: senhas, phishing, backups, boas práticas  

### 📗 NÍVEL INTERMÉDIO (40 horas)
- **Excel Avançado**: funções lógicas (SE, E, OU), PROCV, PROCH, tabelas dinâmicas, dashboards  
- **Manutenção de Computadores**: limpeza, troca de componentes, instalação de sistemas  
- **Introdução à Programação**: lógica, algoritmos, fluxogramas  
- **Ferramentas de Produtividade**: Google Drive, Teams, Zoom  
- **Trabalho Colaborativo**: partilha de ficheiros, edição simultânea  

### 📕 NÍVEL AVANÇADO (40 horas)
- **CAD**: com base no `ebook_cad72020v1.pdf`  
- **Redes Avançadas**: endereçamento IP, sub-redes, roteamento, servidores  
- **Administração de Sistemas**: Windows Server, utilizadores, permissões  
- **Segurança Avançada**: firewalls, antivírus, criptografia  
- **Projecto Integrador**: consolidação prática de todos os conhecimentos
